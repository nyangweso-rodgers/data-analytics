# Drop MySQL Database Tables

```sh
    # Drop specific table(s):
    py drop_mysql_db_tables.py --tables customers
    py drop_mysql_db_tables.py --tables customers account installment_schedules

    # Drop ALL configured tables:
    py drop_mysql_db_tables.py --tables all

    # Interactive mode (no arguments):
    py drop_mysql_db_tables.py
```
